Msg-forwarder-Go

Предпросмотр вкладки LuCI 25.12+ (локальная копия для сравнения). Секретные поля показывают только признак «установлено».

Подключения

VK: off — не настроено: нет vk_token
MAX: off — не настроено: нет max_token/max_device_id
TG: on — готов к отправке
BARK: on — готов к отправке
SMS-авторизация MAX доступна только во встроенном интерфейсе: включите его галочкой ниже.
Нет вывода

Управление сервисами

Управление процессом

VK

Получить через OAuth ВКонтакте с правами messages или скопировать из настроек своего приложения.
Создайте приложение в разделе «Разработчикам → Приложения» ВКонтакте и скопируйте его ID.
Версия Long Poll API, например 5.131. Обычно менять не нужно.

MAX

Временный токен веб-версии MAX. Скопируйте из браузера или получите через SMS-авторизацию во встроенном интерфейсе.
Идентификатор устройства из того же сеанса MAX, что и токен.
Адрес подключения MAX. По умолчанию wss://api.oneme.ru/websocket.
User-Agent браузера, из которого получен токен. Должен совпадать с сеансом MAX.
Версия веб-клиента MAX, например 26.11.9.
Код события входящего сообщения. По умолчанию 128; если сообщения не приходят — попробуйте другое значение.

Telegram

Получите у @BotFather командой /newbot.
Чат, куда бот шлёт сообщения. Сначала напишите боту /start. Для личной переписки подойдёт ваш ID от @userinfobot; для группы добавьте бота в группу и возьмите chat.id из ответа getUpdates или у @get_id_bot.
Необязательно. Адрес HTTP/SOCKS5-прокси только для Telegram, например socks5://127.0.0.1:1080.

Bark

Программа отправляет POST /push с JSON. Вкладки GET и POST в приложении Bark — только примеры запроса, заполнять их не нужно. Поле body — это текст самого сообщения, оно подставляется автоматически.
Базовый URL из приложения Bark, например https://api.day.app. Программа сама добавит /push.
Длинный ключ из ссылки Bark после адреса хоста (в документации пример на 22 символа). Это НЕ ключ шифрования; ограничения по длине нет.
Ровно 16 символов из раздела «Push Encryption → Encryption Settings» приложения Bark. Нужен только при включённом шифровании.
Поставьте галочку, если в Bark включено шифрование, и вставьте тот же ключ выше.
Поле title в JSON Bark. К нему автоматически добавится источник сообщения.
Поле sound в JSON Bark, например birdsong.
Поле group в JSON Bark.
Поле level в JSON Bark: active, timeSensitive, passive или critical.
Поле icon в JSON Bark — ссылка на картинку.
Поле url в JSON Bark — адрес, который откроется по нажатию.

Автозапуск и интерфейс

Подключаться к VK автоматически при запуске программы.
Подключаться к MAX автоматически при запуске программы.
Готовить отправку в Telegram автоматически.
Готовить отправку в Bark автоматически.
Включить локальную панель. По умолчанию выключена, порты не занимаются.
Адрес и порт встроенной панели, например 127.0.0.1:8080.
